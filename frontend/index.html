📋 Data Provenance: Hybrid mode loads a real, de-identified prescriber-level slice (data/raw_hybrid/cms_crm_dataset.csv) assembled from public CMS aggregate prior-prescriber, IDR, and Open Payments records — 400 HCPs, no patient PII, no per-patient prescribing records — then overlays an exogenous synthetic CRM detailing layer (call/sample activity, sales-rep assignment). Synthetic mode generates fully statistical profiles with the same schema. The causal Rx_Lift_Pct is an engineered campaign-effect column in both modes. No real patient data is used or derived anywhere in the pipeline.
